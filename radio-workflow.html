Export the track times *

Rekordbox History

Right after recording, export that session's History — it's the list of when each track came in. Do it now, at the decks; it's a separate step from making the video.

* finicky — read the note
* About the track times. Rekordbox's built-in recording .cue came out empty — no track markers — so it took some digging to get timestamps. Two reliable routes: export the History session (has the times), or if that comes up short, audio-match the recording against your source track files (match_mix.py) or tap them in by ear (tap_times.html). Whichever you use, the times get reviewed and locked into tracklist.json in Phase 3.
3

Make the video

Radio/render → Radio/Week N

Turn the recording into the Now-Playing YouTube video. No camera, no editor.

3.1

Save the files into the week folder

Radio/Week N/

Drop the recorded mix.wav and the History export into Radio/Week N/ (Week 1, Week 2, …). That folder is the home for the whole episode — audio, times, video, everything.

3.2

Run one command → the MP4

make_episode.py

In the project, run:
python Radio/render/make_episode.py --week N
It finds the mix + times, pulls the tracklist, and renders CWR_EpN_YouTube.mp4 into the week folder — 1080p, per-track slide with cover, date & venue, progress bar. If the times need recovering it tells you exactly how; review/tweak them in tracklist.json and re-run — no re-matching.

new · one command

Where everything lives

Each episode gets its own Radio/Week N/ folder. The tools and the station artwork stay put.

Radio/ ├─ Artwork/ the show's cover art (Radio_Thumbnail.jpg) ├─ render/ the tools — scripts, never edited per-episode │ ├─ make_episode.py one command → the video │ ├─ match_mix.py audio-match timestamps from source tracks │ ├─ tap_times.html tap-along timestamps by ear │ └─ weekly_prep.py cues · chapters · buy list · checklist ├─ Week 1/ ← this episode: everything for it │ ├─ 01 CWR_Ep1_Final.wav the recorded mix │ ├─ HISTORY ….m3u8 Rekordbox session export │ ├─ tracklist.json the locked timestamps │ ├─ youtube_chapters.txt paste into YouTube │ ├─ EP1_cues.csv / _checklist working files │ └─ CWR_Ep1_YouTube.mp4 the finished video └─ Week 2/ next episode…
How the video path got easier: Phase 3 used to be "figure out a video editor." It's now one command with the cover, tracklist and show info pulled for you. The finicky part — recovering track times from a recording whose .cue was empty — is handled by History export, audio-matching, or tap-along, and locked into tracklist.json so you can hand-correct and re-render anytime. Nothing about your recording setup changed.
